1.2.1 遗失的校卡（修订版）

【场景：教室·中午放学】
【BGM：校园日常】

【旁白】中午，同学们陆续离开。我收拾好东西，却发现 B 还坐在座位上翻书包。

我：怎么了？不去吃饭？
B：……校卡找不到了。
我：上午不是还用过？
B：嗯，应该带了。
我：两个人找快一点。
B：……那麻烦你了。

【旁白】书包夹层、桌洞、课本、桌底，全找过了，还是没有。时间一点点过去。

我：你该不会落宿舍了吧？
B：应该不会……
我：等等，你外套找过没？
B：外套？

【旁白】B 摸了摸搭在椅背上的外套侧兜，动作突然停住。他慢慢掏出一张校卡。

我：……
B：……
我：找到了？
B：……嗯。对不起。
我：哈哈，合着一直在你椅子上。
B：真的忘了。
我：下次先摸口袋。走吧，食堂估计吃不上了。
B：……去中餐厅吧。我请你。
我：AA 就行。
B：好。

【场景切换：中餐厅·靠窗】
【BGM：轻松】

【旁白】等菜时，我注意到 B 书包上的苦力怕挂件。

我：诶，我看到你的挂件，你也玩 Minecraft吗？

B：你也玩？

我：对啊，玩了好几年了。

B：我也是。

我：你平时玩 Java 版还是基岩版？

B：Java 版多一点。你呢？

我：一样。我平时主要玩生存，偶尔也喜欢搞搞建筑。

B：我也喜欢生存，不过我更喜欢折腾红石。

我：红石？那你应该挺厉害的吧。

B：没有没有，就会做点简单的机器。

我： 我之前跟朋友开过一个生存服，花了好久才把基地建起来。

B： 建的什么风格？

我： 偏现代一点吧，还搞了个挺大的仓库。

B： 然后呢？

我： 然后有一次，我在仓库门口整理东西，突然听到背后“嘶”的一声。

B： 苦力怕？

我： 对，转头已经来不及了，直接给门口炸了个大坑。

B： 哈哈哈，我也遇到过。

我： 最烦的是修完之后，感觉怎么都跟原来不一样。

B： 确实，尤其是地形被炸了之后。

我： 对对对！

B：那你遇到这种旧的物资炸没了或者地形对不上的时候会怎么做呢？

我：上转……不是，当然是找创哥理赔啊。

【旁白】B 笑了起来。和之前不同，他似乎渐渐有了聊天的兴致。

B： 对了，你玩过模组吗？

【接续后面的模组与整合包话题】

【旁白】B 笑了。我们聊起模组、联机、整合包服务器，话比前几天加起来还多。

我：你平时话少，聊 MC 倒是挺能说。
B：……之前不知道聊什么。
我：我也差不多。

【旁白】饭菜上桌。

B：周末回家，要不要一起开生存档？
我：好啊。
B：嗯。

【旁白】一张校卡，让我发现了同桌的另一面。
