# SFLS~我挚爱的时光

深圳外国语学校(SFLS)校园主题视觉小说项目

本项目将由SFLS计算机科学社成员合作开发，使用"Ren'Py 8"引擎制作

## 项目简介

《SFLS~我挚爱的时光》是一款以现实中的深圳外国语学校高中部校园为背景的校园主题视觉小说。

玩家将扮演一名刚刚进入SFLS的高一新生,在逐渐熟悉校园、同学和高中生活的过程中经历各种日常事件。

作品整体以：

· 校园日常

· 角色互动

· 玩梗和亚文化

· 角色成长

为主要风格。

## 剧情结构

目前暂定采用共通主线 + 人物关系支线 + 校园事件短支线 + 多结局


## 开发环境
· 引擎： Ren'Py 8

· 编辑器：Visual Studio Code

· 语言：Ren'Py Script + Python

· 版本管理：Git + GitHub
