游玩方式

下载后，怎样开始游玩？

＋

选择对应系统的游戏 ZIP，完整解压并保留所有文件。Windows 用户运行解压目录内的游戏 .exe；其他平台使用包内对应启动文件。游玩发行包无需另行安装 Ren’Py。

手机、iPhone、iPad 和电脑也可通过在线试玩进入浏览器体验版，建议横屏游玩。网页存档保存在当前浏览器与设备中，请通过游戏菜单导出重要存档。GitHub 自动生成的 Source code 是源码包，直接游玩请选择下方的游戏包。
