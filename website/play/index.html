HOW TO PLAY

慢慢读，随时保存。

  • 点击游戏画面推进对话，点击选项作出选择。电脑也可使用空格或回车。
  • 手机、iPhone 和 iPad 建议横屏游玩。全屏功能是否可用取决于浏览器。
  • 通过游戏下方的“保存 / 读取”管理进度。存档保存在当前浏览器与设备中，清除网站数据或使用无痕模式可能丢失进度。
  • 需要换设备时，可使用游戏左上角菜单的存档导入 / 导出。退出前请先保存。
  • 没有声音时，先点击游戏画面，并检查设备音量、静音状态和游戏设置。加载较慢时，请稍候或切换网络。

网页体验版仍需持续适配。遇到兼容问题，可选择电脑端下载，并通过 GitHub Issues 反馈设备和浏览器版本。
